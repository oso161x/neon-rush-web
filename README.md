NEON RUSH — Crystal Run: a neon arcade game for the browser. Pilot your ship through a crystal storm: catch the falling crystals, dodge the meteors, grab shield / magnet / slow-mo power-ups, and clear 3 levels to win. Keyboard (arrows / WASD) or mouse, with a HUD (score, lives, level, combo), synthesized sound effects, and a start / pause / win / game-over flow.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network: `game/` is plain static files.
